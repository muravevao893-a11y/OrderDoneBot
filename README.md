# Kwork Order Autopost Bot

Бот автоматически публикует в Telegram-канал посты о выполненных заказах.

Лучший безопасный сценарий:

**Kwork → уведомление на отдельную почту → бот читает почту по IMAP → присылает тебе предпросмотр → ты жмёшь «Опубликовать» → пост уходит в канал.**

При желании можно включить полный автомат:

**Kwork → почта → бот → канал без подтверждения.**

## Что умеет

- Отслеживает письма от Kwork через IMAP.
- Ищет письма по ключевым словам: «заказ выполнен», «заказ закрыт» и т.д.
- Вытаскивает сумму, название заказа и дату, насколько это возможно по тексту письма.
- Не публикует дубли: каждое письмо обрабатывается один раз.
- Может работать в безопасном режиме с подтверждением публикации.
- Может работать в полном автоматическом режиме.
- Публикует красивые посты в канал.
- Поддерживает кнопку «Заказать разработку».
- Хранит историю заказов в SQLite.
- Есть ручная команда `/done`, если нужно быстро добавить заказ самому.
- Есть Docker Compose для хостинга.

## Пример поста

```text
✅ ЗАКАЗ ВЫПОЛНЕН

💰 Сумма: 3 000 ₽
🧩 Услуга: Разработка Telegram-бота
📅 Дата: 02.05.2026
🔢 Заказ №: 000001

💬 Автоматически найдено по уведомлению Kwork

Спасибо за доверие 🙌
```

## Установка без Docker

```bash
python -m venv venv
source venv/bin/activate  # Linux/Mac
# Windows:
# venv\Scripts\activate

pip install -r requirements.txt
cp .env.example .env
python bot.py
```

## Установка через Docker

```bash
cp .env.example .env
# заполни .env

docker compose up -d --build
```

Проверить логи:

```bash
docker compose logs -f
```

## Настройка Telegram

1. Создай бота через `@BotFather`.
2. Скопируй токен в `.env` → `BOT_TOKEN`.
3. Добавь бота администратором в свой канал.
4. Дай право публиковать сообщения.
5. Укажи канал в `.env`:

```env
CHANNEL_ID=@your_done_orders_channel
```

или numeric ID:

```env
CHANNEL_ID=-1001234567890
```

6. Укажи свой Telegram ID:

```env
ADMIN_IDS=123456789
```

Узнать ID можно через `@userinfobot`.

## Настройка почты Kwork

Самый чистый вариант — создать отдельную почту только под уведомления, например:

```text
orders.yourname@gmail.com
```

В Kwork укажи эту почту для уведомлений или настрой пересылку писем о заказах на неё.

### Gmail

Для Gmail нужен не обычный пароль, а **App Password**.

В `.env`:

```env
EMAIL_ENABLED=true
IMAP_HOST=imap.gmail.com
IMAP_PORT=993
IMAP_USER=orders.yourname@gmail.com
IMAP_PASSWORD=твой_app_password
IMAP_FOLDER=INBOX
```

## Режимы публикации

### Безопасный режим, рекомендую для старта

```env
AUTO_PUBLISH=false
```

Бот найдёт письмо, создаст предпросмотр и пришлёт тебе кнопки:

- ✅ Опубликовать
- 🗑 Пропустить

Так меньше риск случайно выложить не тот текст.

### Полный автомат

```env
AUTO_PUBLISH=true
```

Бот сам публикует пост в канал, когда находит письмо о выполненном заказе.

Совет: сначала запусти пару дней в безопасном режиме. Когда увидишь, что письма парсятся нормально, включи полный автомат.

## Важный момент про письма Kwork

Текст уведомлений Kwork может отличаться. Поэтому в `.env` есть настройки:

```env
KWORK_SENDER_FILTER=kwork
KWORK_SUCCESS_KEYWORDS=заказ выполнен,заказ закрыт,работа выполнена,заказ завершен,order completed,completed
```

Если бот не ловит нужное письмо или ловит лишнее — нужно прислать пример письма, и регулярки/ключевые слова лучше подогнать точнее.

## Безопасность

- Не давай боту пароль от Kwork.
- Для Gmail используй App Password.
- Лучше создать отдельную почту под уведомления.
- Не публикуй старые письма: по умолчанию `EMAIL_SKIP_OLD_ON_FIRST_RUN=true`, бот на первом запуске пропускает старую почту.
